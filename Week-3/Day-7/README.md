**Real question:**

---

## ❌ Naive Thinking (What to Avoid)

- Nested loops without pruning
- Sorting when not required
- Rechecking elements unnecessarily
- Overcomplicating logic

These approaches increase time complexity and introduce bugs.

---

## ✅ Optimized Thinking

### Core ideas reinforced today:
- Use sorted structure when available
- Use hashing for constant-time lookups
- Start sequences only at valid boundaries
- Let math and properties (like XOR) do the heavy lifting
- Choose clarity first, then optimize
